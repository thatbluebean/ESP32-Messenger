# Messenger
This is a simple messaging application built using Python and C++. It allows for sending messages between devices.

## Features
- **Python Script (`app.py`)**: Handles message processing and communication.
- **C++ Sketch (`Messenger.cpp`)**: Manages hardware interactions for sending and receiving messages.
- **Shell Script (`send-message.sh`)**: Provides a command-line interface to send messages.

## Setup
1. Clone the repository.
2. Connect your Arduino board.
3. Open `Messenger.cpp` and update it with your WiFi SSID and password.
4. Upload `Messenger.cpp` to your Arduino.
5. Run `app.py` on your Python environment.
